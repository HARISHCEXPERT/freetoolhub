About the PDF Metadata Viewer

The PDF Metadata Viewer instantly shows you everything stored inside a PDF file — page count, dimensions, author, title, creation date, and more. Useful for auditing documents, debugging PDF generation pipelines, or simply checking what is inside a file before sharing it.

How to use the PDF Metadata Viewer

  1. Drop or select your PDF file.
  2. All metadata appears instantly — no button to press.
  3. View page count, author, creation date, page sizes and more.

Frequently asked questions

What metadata does this tool show?

It shows page count, title, author, subject, creator, producer, keywords, creation date, modification date, PDF version and individual page sizes.

Is it free?

Yes, completely free.

Is my PDF uploaded?

No. The file is read locally in your browser — nothing is sent to any server.

Can it read encrypted PDFs?

It will attempt to read metadata even from encrypted files, but some fields may be unavailable.
