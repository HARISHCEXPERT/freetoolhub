Chemical equation balancer

This chemical equation balancer finds the smallest whole-number coefficients that make an equation obey the law of conservation of mass: the same number of atoms of each element on both sides. It writes the atom counts as a set of linear equations and solves them with Gaussian elimination, so it works on equations with many compounds, not just short ones.

How to use it

  1. Type the unbalanced equation, with + between compounds and -> or = between the two sides, for example Fe + O2 -> Fe2O3.
  2. Write formulas with capital letters in the right places, such as Ca(OH)2 or H3PO4. Brackets are supported.
  3. Click Balance to see the balanced equation, the coefficient of every compound, and an atom-count table that shows each element is equal on both sides.

How to balance an equation by hand

Take Fe + O2 → Fe2O3. Count atoms: the left side has 1 Fe and 2 O, the right has 2 Fe and 3 O. Oxygen is the awkward one, and the smallest number divisible by both 2 and 3 is 6, so use 3 O2 and 2 Fe2O3. That gives 4 Fe on the right, so put 4 in front of Fe. The balanced equation is 4Fe + 3O2 → 2Fe2O3. The tool does the same job for you, even when the hand method gets long.

Balanced equation examples

  • H2 + O2 → H2O becomes 2H2 + O2 → 2H2O
  • N2 + H2 → NH3 becomes N2 + 3H2 → 2NH3
  • C3H8 + O2 → CO2 + H2O becomes C3H8 + 5O2 → 3CO2 + 4H2O (propane burning)
  • Al + HCl → AlCl3 + H2 becomes 2Al + 6HCl → 2AlCl3 + 3H2
  • C6H12O6 + O2 → CO2 + H2O becomes C6H12O6 + 6O2 → 6CO2 + 6H2O (glucose)
  • Ca(OH)2 + H3PO4 → Ca3(PO4)2 + H2O becomes 3Ca(OH)2 + 2H3PO4 → Ca3(PO4)2 + 6H2O
  • KMnO4 + HCl → KCl + MnCl2 + Cl2 + H2O becomes 2KMnO4 + 16HCl → 2KCl + 2MnCl2 + 5Cl2 + 8H2O

What it cannot do

The balancer does not read ionic charges (such as Fe3+ or SO4 2−) or state symbols like (s) and (g), so leave them out. Hydrates work, for example CuSO4·5H2O -> CuSO4 + H2O, and every element from hydrogen to oganesson is recognised. If an element appears on only one side, or the equation has no solution in positive whole numbers, the tool tells you why instead of guessing. For a step-by-step method you can do on paper, read how to balance a chemical equation.

Next step: moles and masses

Once the equation is balanced, the coefficients give mole ratios. Use the molecular weight calculator to get the molar mass of each compound, and the periodic table to look up elements.

Frequently asked questions

How does the chemical equation balancer work?

It counts the atoms of each element, writes the balance condition as linear equations and solves them with Gaussian elimination. Then it scales the solution to the smallest whole numbers.

What format should I use for the equation?

Separate compounds with + and the two sides with -> or =. Example: Al + HCl -> AlCl3 + H2. Use correct capitalisation and brackets for groups such as (OH)2.

Can it balance redox equations?

It can balance any equation that is written without ionic charges, including ones like KMnO4 + HCl -> KCl + MnCl2 + Cl2 + H2O. Equations that need charges or half-reaction methods are not supported.

Why do I get an error about positive integer coefficients?

That usually means a formula is mistyped, a product or reactant is missing, or the equation cannot be balanced as written. Check each formula and the capital letters.

Does it work for all elements?

Yes, any element symbol from the periodic table is accepted, including barium, tin and platinum. Capital letters matter: Co is cobalt, while CO is carbon monoxide.

Is the balanced answer unique?

For most simple equations yes. The tool returns the smallest whole-number set of coefficients.
