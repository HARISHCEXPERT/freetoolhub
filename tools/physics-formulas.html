About the Physics Formula Reference

The Physics Formula Reference is a searchable collection of 100+ essential physics formulas covering mechanics, waves and oscillations, thermodynamics, electrostatics and current electricity, magnetism, optics and modern physics. Search by keyword, formula symbol or topic.

How to use the Physics Formula Reference

  1. Type a keyword (e.g. "kinetic energy", "Snell", "ideal gas") to filter instantly.
  2. Or click a topic button to filter by chapter.
  3. All formulas include variable definitions.

Frequently asked questions

Is this tool free to use?

Yes. The Physics Formula Reference is completely free with no sign-up and no limits.

Is my data uploaded to a server?

No. All calculations run in your browser using JavaScript. Nothing is sent to any server.

Does it work offline?

Yes. Once the page is loaded, all computations work without an internet connection.

Does it work on mobile?

Yes, it works in any modern browser on desktop, tablet and mobile.
