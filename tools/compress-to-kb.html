Compress an image to the size you need

Many online forms, portals and email systems limit how large an uploaded image can be. This free tool shrinks a photo or signature to a maximum size in KB that you choose. It tries different JPEG quality levels, keeps the highest one that fits, and scales the picture down only when quality alone is not enough.

Everything happens in your browser, so your pictures are never uploaded. Check your form's instructions for the exact size, format and dimensions it asks for.

How to use it

  1. Click the box above or drag an image onto it.
  2. Type the maximum size you need in the Target size box.
  3. Optionally type a width and height for exact pixel dimensions.
  4. Press Compress, check the size shown, then click Download.

Frequently asked questions

How do I compress an image to a specific size in KB?

Choose your image above, type the maximum size you need in the Target size box and press Compress. The tool finds the highest JPEG quality that stays under that limit and only shrinks the picture itself if quality alone is not enough.

Can I set the width and height as well?

Yes. Type a width and a height in the optional boxes and the picture is cropped to fill that size without stretching. If you fill in only one box, the other side follows the original proportions.

Is my image uploaded anywhere?

No. Compression runs in your browser, and the file never leaves your device.

Which file types can I use?

PNG, JPG, WEBP and GIF images open in every modern browser. iPhone HEIC photos depend on your browser, so convert them to JPG first if one will not open. The output is always a JPG.

What if the tool cannot reach my target size?

If you typed both a width and a height, the picture keeps that size, so a very small limit may not be reachable. The tool then shows the best result it could get. Clear the width and height boxes or raise the limit and try again.
