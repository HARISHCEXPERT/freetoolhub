About the IUPAC Name Helper

The IUPAC Name Helper generates correct IUPAC names for straight-chain and simple branched organic compounds — alkanes, alkenes, alkynes, alcohols, haloalkanes and cycloalkanes — for chains up to C20. It also includes a complete functional group suffix and prefix reference table.

How to use the IUPAC Name Helper

  1. Choose the compound type.
  2. Set the chain length (number of carbon atoms).
  3. Set the position of the functional group if applicable.
  4. Click Generate IUPAC Name.

Frequently asked questions

Is this tool free to use?

Yes. The IUPAC Name Helper is completely free with no sign-up and no limits.

Is my data uploaded to a server?

No. All calculations run in your browser using JavaScript. Nothing is sent to any server.

Does it work offline?

Yes. Once the page is loaded, all computations work without an internet connection.

Does it work on mobile?

Yes, it works in any modern browser on desktop, tablet and mobile.
