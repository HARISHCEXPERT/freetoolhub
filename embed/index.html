Free chemistry calculator widget for your website

Teachers, tutors, bloggers and course creators can put a working molar mass calculator or chemical equation balancer on their own page. Copy one block of HTML, paste it where you want the tool, done. It is free, needs no signup or API key, and works in WordPress, Blogger, Wix, Notion-style HTML blocks and any LMS that allows an HTML embed.

1. Molar mass calculator

Type a formula such as H2O, Ca(OH)2 or CuSO4·5H2O and get the molar mass with a per-element breakdown.

<iframe src="https://freetoolhub.app/embed/chem.html" width="100%" height="420" style="border:1px solid #e2e8f0;border-radius:10px" loading="lazy" title="Molar Mass Calculator"></iframe>

2. Chemical equation balancer

Enter an unbalanced equation such as Fe + O2 -> Fe2O3 and get the balanced version, solved with exact fractions.

How to paste it

  • WordPress: add a "Custom HTML" block and paste the code.
  • Blogger: in the post editor switch to HTML view and paste.
  • Wix / Squarespace / Google Sites: use the "Embed code" or "HTML" element.
  • Moodle / other LMS: paste into the HTML source of a page or label.

Good to know

  • The widget runs in the visitor's browser. Nothing they type is sent to a server.
