UPSC photo and signature size: what the portal asks for

Last checked 2026-10-20 · FreeToolHub

UPSC uses its own upload instructions on the online application portal. We could not open the official PDF ourselves while writing this, so the numbers below come from a coaching-site summary of the 2026 guidelines. Please confirm them in the official instruction PDF on upsconline.nic.in before you upload.

PhotographSignature
FormatJPGJPG
File size (as reported)20 KB to 200 KB20 KB to 100 KB
Background (as reported)Plain white, face centred, both ears visiblePlain white, dark ink

Source for the table: Vajiram & Ravi summary. The same page also mentions a live photo capture on the application. Dimensions and other layout rules are in the official PDF, so read that part there.

Mind the minimum. Both files have a 20 KB floor. A clean signature scan can compress below that. After compressing, check the size shown under the result.

Fit your files in a few steps

  1. Open Compress Image to Exact KB.
  2. For the photograph, set the target to 200 KB. For the signature, set it to 100 KB.
  3. Compress and look at the result size. If the file is under 20 KB, type a bigger width and height and run it again.
  4. Rename the downloads to what the portal asks for and upload.

Ready-made pages: photo to 200 KB, image to 100 KB, signature to 50 KB.
